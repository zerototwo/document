# B 树和 B+ 树的区别主要有几点

第一，B 树的非叶子节点和叶子节点都可以存 key 和 data；B+ 树只有叶子节点存完整数据，非叶子节点只存 key 和指针。

<br>

第二，B+ 树非叶子节点更小，一个磁盘页能存更多 key，所以树的分叉更多、高度更低，查询时磁盘 IO 更少。

<br>

第三，B+ 树所有数据都在叶子节点，查询路径更稳定；B 树可能在非叶子节点命中，查询路径不完全一致。

<br>

第四，B+ 树叶子节点之间有链表，非常适合范围查询和排序扫描；B 树数据分散在各层，范围查询效率不如 B+ 树。

<br>

所以 MySQL InnoDB 选择 B+ 树作为索引结构，主要是因为它更适合磁盘存储，IO 次数少，范围查询效率高，并且查询性能更稳定。
